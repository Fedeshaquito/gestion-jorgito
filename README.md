# Gestión del negocio

App web instalable (PWA) para un emprendimiento mayorista: productos y stock, clientes con cuenta corriente, presupuestos en PDF por WhatsApp, ventas y panel de control.

- Funciona en iPhone (Safari → Compartir → "Agregar a inicio") y en la PC.
- Los datos se guardan en el dispositivo (IndexedDB). Hacer copias desde Ajustes.

## Desarrollo

```
npm install
npm run dev      # servidor local
npm run build    # genera la carpeta dist/ para publicar
```
